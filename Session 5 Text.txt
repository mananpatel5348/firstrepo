Q-1 :- Write the Git command for each: initialize a repo, stage all files, commit with a message, push to remote, pull latest changes.

Ans :- 1. Initialize a Repository :- git init

       2. stage all files :- git add .

       3. commit with a message :- git commit -m "your message"

       4. push to remote repo :- git push origin main 

       5. pull latest changes :- git pull origin main

------------------------------------------------------------------------------------------------------------------------------------------------

Q-2 :- What is the difference between git fetch and git pull? Answer in 2 lines

Ans :-  git fetch – Latest changes ko download karta hai, lekin merge nahi karta.

        git pull – Latest changes ko download karke automatically current branch me merge kar deta hai.
