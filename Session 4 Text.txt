Q-1 :- List all 6 phases of SDLC in order with one line about each.

Ans :- 1. requirement Analysis :– Customer ki requirements collect aur analyze ki jati hain.

       2. Design :– Software ka design aur architecture tayyar kiya jata hai.

       3. Development :– Software ka code likhkar application banayi jati hai.
      
       4. Testing :– Bugs dhoondhkar software ki quality check ki jati hai.

       5. Deployment :– Software ko users ke liye release kiya jata hai.

       6. Maintenance :– Bugs fix kiye jate hain aur software ko update aur improve kiya jata hai.
