Q-1 :- What are the three main layers of software architecture? Write one line about each.

Ans :- Layer 1 :- Presentation Layer – User interface ko handle karti hai aur user se input leti hai.

       Layer 2 :- Business Logic Layer – Application ke rules aur processing ko manage karti hai.
       
       Layer 3 :- Data Layer – Database me data ko store aur manage karti hai.
